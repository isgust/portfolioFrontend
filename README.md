# Portfolio — Frontend

Frontend em React + TypeScript + Vite + Tailwind CSS para o Portfólio Full-Stack.

## Funcionalidades
- Interface estilo Shorts com navegação fluida por seções.
- Sistema de Likes e Comentários integrados com a REST API backend.
- Design responsivo com animações CSS modernas.

## Como Executar Localmente

1. Instale as dependências:
   ```bash
   npm install
   ```

2. Execute o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

3. O frontend estará disponível em `http://localhost:5173`.
   Certifique-se de que o backend Spring Boot esteja rodando em `http://localhost:8080`.
